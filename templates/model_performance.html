Limitations and known weaknesses

  • {% if m.dataset.type == 'synthetic' %}The training data is synthetic; real resumes vary far more in wording, layout and quality.{% else %}Results depend on how representative the training data is.{% endif %}
  • Closely related roles (for example Data Scientist, Machine Learning Engineer and Data Analyst) overlap heavily in vocabulary and are confused most often; see the confusion matrix.
  • The model reads vocabulary only. It does not understand seniority, depth of skill, or the quality of the work described.
  • The suitability score is a documented heuristic and has not been validated against hiring outcomes. It is not a probability of being hired.
  • The "model probability" is the classifier's probability for the predicted category. Its calibration error on the test split is {{ '%.3f' % m.test_metrics.expected_calibration_error }} (0 is perfect), which is only as trustworthy as the test data.
